# PassPonyCore

The shared Rust core for PassPony, a password manager for `pass` (the standard
unix password store) and `passage` (the age-based fork) stores. One core,
platform-native crypto, byte-faithful compatibility with the real CLIs.
Consumed by the platform apps: PassPony (iOS), PassPonyDesktop, PassPonyAndroid.

## Layout

- `crates/pass-core` — store model, entry codec, recipient resolution,
  git engine, TOTP, sync policy. No crypto: everything cryptographic goes
  through the `CryptoBackend` trait, implemented per platform.
- `crates/pass-ffi` — UniFFI bindings (Kotlin, Swift) over pass-core.
  `CryptoBackend` is exposed as a foreign-implemented callback interface so
  each platform plugs in its native engine.
- `docs/` — design notes and spike memos.

## Principles

- The fixture corpus generated by the real `pass`, `passage`, and `gopass`
  binaries is the spec. Prose loses to fixtures.
- Round-trip fidelity is a hard gate: editing one field leaves every other
  byte of the plaintext identical.
- Decrypted content never touches disk. Entry names are plaintext by design;
  no obfuscation layer.

## Building

```
cargo build --locked
cargo test --locked
```
